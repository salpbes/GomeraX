DAILY WORKFLOW (After you set up Git)
═══════════════════════════════════════════════════════════════════════════════

Every time you code:

1. Make changes to your files (as normal in VS Code)

3. Stage files (click + button)

6. Click Push

Time: Usually 1-2 minutes per day
