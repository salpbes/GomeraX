GITHUB QUICK START - FOR OBC-IFCViewer PROJECT
==============================================

ONE-TIME SETUP (Do this once):
═════════════════════════════

1. Create GitHub account at https://github.com (choose username)

2. Install Git (check if installed):
   git --version

3. Configure Git with your name and email:
   git config --global user.name "Your Name"
   git config --global user.email "your-email@example.com"

4. Create empty repository on GitHub at https://github.com/new
   - Name: OBC-IFCViewer
   - Public or Private (your choice)
   - Add .gitignore (select "Node")
   - Add LICENSE (select "MIT")

5. In Terminal, go to your project folder:
   cd /Users/yagmurbesher/Documents/sources/OBC-IFCViewer

6. Initialize Git:
   git init

7. Add all files:
   git add .

8. Create first commit:
   git commit -m "Initial commit: Complete OBC IFC Viewer with Floor Plan feature"

9. Connect to GitHub (replace YOUR-USERNAME with your GitHub username):
   git remote add origin https://github.com/YOUR-USERNAME/OBC-IFCViewer.git

10. Rename branch to main:
    git branch -M main

11. Upload to GitHub:
    git push -u origin main

12. Verify on GitHub: https://github.com/YOUR-USERNAME/OBC-IFCViewer
    You should see all your files! ✅

TROUBLESHOOTING:
════════════════

Q: I see "fatal: 'origin' does not appear to be a 'git' repository"
A: You skipped the "git remote add origin" step. Run it now:
   git remote add origin https://github.com/YOUR-USERNAME/OBC-IFCViewer.git

Q: I see "Permission denied" during git push
A: Create a Personal Access Token on GitHub and use it as password
   More info: See GITHUB_SETUP_GUIDE.md

Q: My files didn't upload
A: Check 3 things:
   1. Did you run "git push"? (not just "git commit")
   2. Do you see "✅ All 100+ files uploaded" message?
   3. Is your GitHub username correct in the remote URL?

Q: I want to see all my changes
A: Type: git log --oneline
   This shows all commits with messages


FIRST TIME USERS - REMEMBER:
════════════════════════════

✅ Git = Software on your computer (tracks changes)
✅ GitHub = Website storage (stores your code online)
✅ Repository = Your project folder on GitHub
✅ Commit = Taking a snapshot of your changes
✅ Push = Uploading to GitHub
✅ Pull = Downloading from GitHub

IMPORTANT FILES TO IGNORE (already in .gitignore):
═════════════════════════════════════════════════

These should NOT be uploaded:
- node_modules/         (downloaded with npm install)
- dist/                 (generated when you run build)
- .env                  (private settings)
- .DS_Store             (macOS system file)

If these get uploaded by accident, see GITHUB_SETUP_GUIDE.md section "Problem: '.gitignore not working'"
